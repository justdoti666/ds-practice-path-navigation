## 5. 接口交接

```python
@dataclass
class Result:
    algorithm: str; found: bool; path: list[str]
    distance_km: float; time_min: float; transfers: int | None
    expanded: int; elapsed_ms: float
    events: list[tuple[str, str]]      # [("settle", sid), …] 供 UI 动画

dijkstra(g, start, goal, weight="time"|"distance") -> Result
astar(g, start, goal, weight) -> Result
bfs_transfers(g, start, goal) -> Result
solve(g, start, goal, algorithm, weight="time") -> Result
analyze_path(g, path) -> (km, min, line_seq, transfers)
# 异常：PathNotFound（不连通）、DataError（参数/站点非法）
```

- **给 P3**：`Result` + `solve()`（D1 骨架，D5 完整）
- **给 P4**：同上；P4 的自检会直接调用三算法做断言
- **我给报告**：第 3 章 + 第 2 章的"堆与状态空间"两小节

## 8. 我的坑

| 坑 | 正确做法 |
| --- | --- |
| A\* 时间权重直接用欧几里得 | 必须 `/ v_max × 60`，否则快线场景非最优 |
| 用曼哈顿距离当 `h` | 任意方向图上会高估，破坏最优性；只放对比实验里"故意错" |
| 最少换乘写成普通 BFS | 站点当节点只会得最少站数；必须 `(站点,线路)` 状态 |
| 堆里塞重复节点后不判 `done` | 用 `done` 集合 + 懒惰删除，否则 `expanded` 虚高 |
| `expanded` 统计口径不一 | 统一"出堆且未访问过"计 1，写进注释 |
| 时间太短测性能 | `perf_counter` + 3 次中位数 + 大图（≥100 站）才谈 ms |
| 把失败当 0 距离 | 不连通抛 `PathNotFound`，别返回空路径 |
