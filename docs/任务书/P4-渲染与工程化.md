## 8. 我的坑

| 坑 | 正确做法 |
| --- | --- |
| 初始 1×1 时算坐标，之后一直错 | 首次 `<Configure>` 后防抖重绘（120ms） |
| 用固定像素画图，缩放就糊/变形 | 世界坐标 → 屏幕坐标每次重算，保持等比 |
| 动画里 `sleep` | `after()` 链式调度；暂停=不排下一帧 |
| 动画中切算法，旧帧继续跑 | 动画前 `after_cancel` 旧 job + 清 `anim` 标签 |
| 缩放后点击偏移 | 命中也走同一套坐标变换，别用旧 `self.pts` |
| 导出图文字糊 | `postscript` 或高 dpi 截图；导出后人工看一眼 |
| 自检断言恒真 | 每条断言先"故意写坏实现"验证能红 |
