# 00 · 总览与协作规则（四份任务书共用）

> 城市交通路径导航系统（数据结构实践 · 选题 A） ｜ v1.0 ｜ 2026-10-17
> 四份个人任务书：[[P1-数据与建模]] · [[P2-算法引擎]] · [[P3-界面与交互]] · [[P4-渲染与工程化]]
> 架构与接口契约：`docs/技术方案.md`（§6 契约、§4 算法、§5 界面）

## 1. 项目一句话

把城市线路抽象成图（邻接表），用 **Dijkstra / 0-1 BFS 最少换乘 / A\*** 三种口径做路径搜索，
用 Tkinter 画出来（点选、高亮、动画），并用自检矩阵 + 对比实验支撑实验报告。

## 9. 质量门（每个任务收尾必过）

1. `python main.py --check` 全绿，且新增功能有对应断言；
2. `git status` 里只有自己名下的文件；
3. 无调试 `print`、无硬编码绝对路径；
4. UI 改动附截图（站名不重叠、控件不被裁切）；
5. 提交信息合规，且已请另一位组员 review。

## 10. 砍需求顺序（时间不够时从后往前砍）

录屏 → 缩放/拖拽 → 动画速度档 → 真实数据（≥30 站即可）→ 界面美化。
**永不砍**：三算法正确性、`--check` 自检、报告三张核心表（复杂度 / 对比实验 / 正确性验证）。
