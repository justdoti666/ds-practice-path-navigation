## 8. 我的坑

| 坑 | 正确做法 |
| --- | --- |
| 在主线程 `sleep` 做动画 | 一律 `widget.after(ms, fn)`；算法先算完再播 |
| 界面里自己算最短路 | 只调 `solver.solve()`；界面层禁写算法 |
| 下拉框存了中文名导致查不到 id | 统一存 `站名（ID）`，用 `rsplit("（",1)` 取 id |
| 未选点/空图直接崩 | 先校验再调用；异常分支要有测试 |
| 窗口缩放后内容错位 | 交给 P4 的 `CanvasView` 重绘；我不自己算坐标 |
| 对比表数值与 bench 不一致 | 同一份 `bench.csv` 喂两处，禁止手抄 |
