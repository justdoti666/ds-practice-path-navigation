## 5. 接口交接（我给谁什么）

```python
load_graph(path) -> Graph
Graph.stations: dict[str, Station]        # Station(sid, name, x, y)，坐标单位 km
Graph.lines: dict[str, {name, speed_kmh, color}]
Graph.edges: list[Edge]                  # Edge(u, v, line, distance_km, time_min)
Graph.neighbors(sid) -> list[Edge]
Graph.edge_between(u, v) -> list[Edge]
Graph.lines_of_station() -> dict[str, set[str]]
Graph.bbox() -> (x0, y0, x1, y1)
Graph.add_station/add_edge/remove_edge   # P1-06 新增
```

## 8. 我的坑（先看，能省半天）

| 坑 | 正确做法 |
| --- | --- |
| 坐标单位混乱 | 一律 **km**；`distance_km` 缺省 = `hypot(dx,dy)`，别用经纬度 |
| TXT 读到 BOM 导致首个 `[meta]` 认不出 | 读文件用 `encoding="utf-8-sig"` |
| 校验写在算法里 | 一律在**加载阶段**抛 `DataError`，算法层不兜底 |
| 真实数据缺坐标 | 按线路顺序线性布局（x 递增、换乘站合并），并在 `meta.note` 注明" approximated " |
| 平行边（两条线共走廊） | 允许 `(u,v,line)` 唯一，不合并线路 |
| 自己改 `Graph` 字段没通知 | 先改 `docs/契约变更.md` + bump 版本，再动代码 |
