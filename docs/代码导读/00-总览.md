## 一句话架构

```
data/*.json|txt
      │  core/graph.py::load_graph（P1：加载 + 校验）
      ▼
   Graph（站点/边/线）
      │  core/solver.py（P2：Dijkstra / A* / 0-1 BFS）
      ▼
   Result（path / lines / 指标 / events）
      │  ui/window.py（P3：窗口、状态机、异常、面板）
      ▼
   CanvasView（P4：绘制、交互、动画）
        └─ ui/display_layout.py：只给“画”用的示意坐标（不改数据坐标）
```

## 契约

- `core.CONTRACT_VERSION = 1.3.0`；规则：**只加不改**，改动要写 `docs/契约变更.md`。
- 三层单向依赖：`ui → core`，`core` 不 import `ui`；P4 画布不碰算法数值。
