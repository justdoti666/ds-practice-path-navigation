## 2. 阅读顺序（按行号）

1. `ui/p4_canvas.py:759` `CanvasView` 构造 → `:859` `bind_click` → `:864` `show_path` → `:873` `animate`。
2. `:1278` `_redraw()`——**绘制顺序**：网格 → 底图线路 → 搜索路径 → 站点 → 起终标记 → 分段标注 → 站名 → 图例/信息卡 → 悬停。
3. `:1371` `_draw_lines()`、`:1404` `_shared_corridors()`——并行走廊（2/7 号线广州南站—石壁）向两侧画小弧，避免两条线压成一条。
4. `:1524` `_draw_path_line()`——路径画在线路之后，所以不会被底图盖住。
5. `:1690` `_label_budget()`、`:1695` `_label_visible()`、`:1713` `_layout_station_labels()`、`:1817` `_draw_station_labels()`——站名碰撞、优先级、LOD（1× 只显示关键站）、9/8pt 字号下限、长名截断。
6. `ui/canvas.py:76` `_CanvasGraph`——显示坐标代理；`:128` `show_selection`、`:151` `animation_duration_ms`、`:156` `animate(on_done=)`——P3 需要的补丁。
7. `ui/display_layout.py:104` `station_positions()`、`:137` `needs_schematic_layout()`、`:162` `schematic_layout()`——按拓扑生成示意坐标（PivotMDS + 力导向），只用于画；`:77` 指纹缓存。
8. `tools/export_canvas.py`（无头截图）、`tools/layout_report.py`（几何验收）、`docs/布局修复证据/README.md`（前后对比）。

## 3. 核心口径

- **显示坐标 ≠ 数据坐标**：`_CanvasGraph` 只改画布；`_segment_metrics` 用真实 `graph.stations` 算 km/min。
- **路径永远在底图之上**：`_redraw` 中 `_draw_lines()` 之后才 `_draw_path_line()`。
- **169 站不糊成一束**：示意布局铺开 + 并行走廊小弧 + LOD 标签。
- **demo 不重排**：10 站走数据坐标，静态画布与修复前逐字节相同。

## 7. 坑

- 高 DPI 截图前先 `SetProcessDpiAwareness(2)`，否则窗口会被裁一半。
- 隐藏的站名靠 hover 显示，不是“丢数据”。
- 示意布局只表达拓扑，不表达真实地理方位；正常线路交叉保留。
