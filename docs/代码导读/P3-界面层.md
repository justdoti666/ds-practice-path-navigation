## 2. 阅读顺序（按行号）

1. `ui/window.py:167` `SearchState`、`:227` `Controller`——纯 Python 状态机，不依赖 Tk，测试直接驱动它。
2. `:399` `compare()`、`:430` `compare_with_bench()`——三算法对比与基准校验。
3. `:445` `MainWindow`、`:954` `_on_search()`、`:975` `_on_search_done()`、`:993` `_on_search_failed()`——一次搜索的完整生命周期（异步队列 + token 防串台）。
4. `:1418` `build_window()`、`:1454` `create_window()`、`:1467` `run_gui()`、`:1475` `smoke()`——入口与冒烟；`create_window` 就是 `--data` 生效的地方。
5. `ui/widgets.py`——自绘按钮与统一提示弹窗。
6. `ui/p3_compat.py`——P3 与真实 P1/P2 的薄适配（`load_graph` 接受文件/目录、`is_empty/iter_edges`）。
7. `tests/test_p3_ui.py:96` 状态机、`:167` 异常分支、`:223` 站名解析、`:242` bench 对比。

## 3. 核心链路

```
控件事件
  → Controller.set_start/set_end/begin_search
  → MainWindow._on_search（异步 perform，token 防连点/取消）
  → _on_search_done → apply → canvas.show_path / animate
  → _render_path / _render_compare 更新面板
```
