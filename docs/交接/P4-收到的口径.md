## 1. 两套测试是**有意重复**的，不要合并

| 套件 | 归属 | 颗粒度 | 用途 |
| --- | --- | --- | --- |
| `selfcheck.py`（`main.py --check`，10 组断言） | **你（P4）** | 端到端 | 「整个程序能不能交付」：数据对拍、算法等价、边界、异常、界面冒烟 |
| `tests/`（`unittest discover`，18 条） | P2 | 算法层 | 全点对属性测试、独立 oracle 对拍、红绿判别 |

- 两者各写了一份**暴力枚举换乘**的 oracle（`selfcheck.brute_min_transfers` 与 `tests/support.brute_min_transfers`），**故意独立**；删掉一套就失去"两套实现互相印证"的意义。
- 你会重复看到"A\* 与 Dijkstra 同代价"两条断言：那是**守门人**，只可加不可删。

## 4. 插图维护

`docs/figs/*.png` 由 `tools/make_figs.py` 生成，脚本内含**像素自检**（非白像素比例断言，防止生成空白图）。
改配色/字号时保留 `--out` 参数与自检；重画后同步报告图注编号（图 3-1 / 3-2 / 3-3 / 4-1）。

## 5. 动画的唯一入口是 `Result.events`

- 逐帧上色只消费 `result.events`（`[("settle", sid), …]`），**不要在渲染层另算搜索过程**——会出现「动画与结果不一致」。
- 切换算法前 `after_cancel` 旧动画并清画布，避免旧帧继续跑。
- 「动画」与「立即求解」同一对起终点必须数值一致（你的冒烟测试可以固化这条）。
