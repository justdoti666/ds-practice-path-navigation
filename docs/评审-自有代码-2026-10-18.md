## 2. 问题清单

### 高（已在本轮修复）

**H1 · `--smoke` 假通过 + 硬编码站点 + 模态框阻塞** 🔴→✅

- 位置：`ui/window.py::smoke`（旧版 310–319 行）、`ui/window.py::search`（旧版无 silent 参数）。
- 现象（用户运行截图确认）：窗口标题是 `mini` 数据，但下拉框被写死为「大学城（S4）/机场（S11）」⇒ 弹「数据错误：起终点不在图中: S4 / S11」；而 `smoke()` 不检查结果，继续 `postscript` 导出并 `return 0`，`main.py` 打印 `smoke ok`。
- 探针证据：同一流程里 `app.search()` 返回 `None`、`app.current is None`；导出文件只有 9048 B（demo 数据是 22563 B）。
- 修复（已提交）：
  1. `core/solver.py` 新增 `pick_connected_pair()`（O(V+E)：先试 S4→S11，否则取首个连通分量里字典序最小的两站，全孤立返回 None）；
  2. `ui/window.py::search(..., silent=False)`：自动化路径不弹模态框，只写日志；
  3. `smoke()` 用自动选点 + **断言 `current is not None and found`**，失败抛错让 `main.py` 返回非 0；
  4. 新增单测 **T18**（demo→S4/S11、tiny→A/B、孤立图→None）。
- 复验：mini 10957 B（路径真的画上去了）、demo 22563 B、无连通图 **exit 1**、19 测全过、自检仍 ALL PASS。

### 中

**M1 · 画线口径与"换乘"口径不一致（并行线路时）**

- 位置：`ui/window.py:170` `e = min(candidates, key=lambda x: x.time_min)`（画线取每跳最快边）。
- 而 `Result.transfers` 来自 `solver.analyze_path()` 的 DP（取**最少换乘**的线路组合）。
- 探针（`tests/support.parallel_lines()`：A-B 同时有 L1/L2，B-C 只有 L1）：
  `analyze_path(["A","B","C"]) → ['L1','L1'] / 换乘 0`，但画线取到 `['L2','L1']` ⇒ **画的是 L2 的边，却报 0 次换乘**。
- 建议：`Result` 增加 `lines: list[str]`（`analyze_path` 已经算出来了，`_result` 里被丢掉），UI/画布按 `lines` 画；或 UI 直接调用 `analyze_path` 取线路序列。

**M2 · 站名重复未拒绝，`main.resolve()` 静默取首个**

- 位置：`core/graph.py::_add_station` 只查 id 重复；`main.py::resolve()` 按名字匹配后返回第一个。
- 探针：两站都叫「同名」→ 加载成功；`resolve("同名")` 返回 `A`（无提示）。
- 建议：加载期查重站名并抛 `DataError`；`resolve` 命中多个时列出候选并报歧义。

**M3 · `tools/bench.py` 默认写入仓库文件，复跑即脏**

- 位置：`tools/bench.py:142` `--out` 默认 `tools/bench.csv`（汇总文件同名派生）。
- 实测：复跑一次 → `git status` 出现 `M tools/bench.csv`、`M tools/bench_summary.csv`（已还原）。
- 建议：默认输出到 `_smoke/` 或 `build/`，显式 `--update-docs` 才写回 `tools/`，并在 `docs/bench.md` 里写清"入库产物由哪条命令生成"。

**M4 · 报告插图的数据源与 bench 产物不匹配（0 柱）**

- 位置：`tools/make_figs.py:117` 硬编码 `grid-16/grid-30/grid-60/grid-240`；而 `tools/bench_summary.csv` 只有 `grid-30/grid-60/grid-240`（`grid-16` 只在 `--scale` 产物里）。
- 实测：`grid-16` 缺失 ⇒ 柱状图第一组会画成 0 高，并标一个 `0`。
- 建议：`want` 从 CSV 实际数据集动态生成，或固定跑一遍 `--scale 15,...` 再画。

**M5 · `--check --data 自定义文件` 会误报"站点集合不同"**

- 位置：`main.py::run_check` 把 `--json` 传成用户数据、`--txt` 固定成 `data/demo_city.txt`。
- 实测：`python main.py --check --data <2 站 mini.json>` → `[1] FAIL 两种格式实现同一张图: 站点集合不同`（其实只是两份数据不同，不是格式不等价）。
- 建议：`--check` 时按 `--data` 的后缀自动找同名 `.json`/`.txt` 对拍；找不到就跳过该项并说明；或加 `--no-cross-format`。

**M6 · 没有 CI，闸门靠人跑**

- 现状：本地三条命令（单测/自检/bench）都绿，但 GitHub 上没有 workflow；队友改完代码不会自动拦。
- 建议：加 `.github/workflows/ci.yml`：`pip install pillow` + `python -m unittest discover -s tests -t .` + `python main.py --check` + `python tools/bench.py --check-cv 15`（headless 可行：我们的 `selfcheck.py` 不含 Tk，已确认）。
