## 拍图环境

* Windows 10/11，Tk 8.6，Python 3.14，Pillow 12（`ImageGrab` 截屏）。
* 程序固定按 96 DPI 排版（`build_window` 里设置 `tk scaling`），因此 125%/150% 缩放的屏幕上
  控件也不会互相挤压；截图前设置进程 DPI 感知，保证文字清晰。
* 字体：Microsoft YaHei UI（缺失时自动回退到系统可用中文字体）。
* 站名不遮挡：`CanvasView` 用候选位置打分排版（避开站点、其他站名、图例、路径），并用四向
  描边字保证线网从字缝中可见。

## 已知取舍

* 动画速度有 1×/2×/3× 三档，截图取 1×。
* 对比表中的"耗时 ms"每次运行都会波动，属于正常现象；与 `bench.csv` 的校验只比较里程、时间、
  换乘次数与扩展节点数这四项稳定值。
